# Yobou Brand Guide

## Brand Essence
Yobou is a premium digital marketplace brand designed to feel modern, trustworthy, and upscale. The identity combines a strong commerce signal with a refined luxury aesthetic.

## Core Brand Colors
- Primary Blue: #0034B9
- Deep Navy: #091F52
- Premium Gold: #D9A21C
- Soft Gold: #F7D777
- Light Gold: #FFF1B0
- White: #FFFFFF
- Dark Text: #0B1C30

## Typography
- Headline: Be Vietnam Pro / Poppins / Segoe UI Bold
- Secondary: Segoe UI / Inter / system sans-serif
- Style: modern, condensed, confident, premium

## Logo System
### Main Mark
The Y-based monogram is the core brand symbol. It is built to look like a high-end retail bag / storefront signal with a premium gold accent.

### Wordmark
Yobou Market
- Yobou in bold modern sans-serif
- Market in uppercase tracking for a stronger retail signal

## Recommended Usage
- Use the premium SVG for web/app headers
- Use the square app icon for mobile launchers and favicons
- Use the splash version for onboarding / cold start screens
